# AulaLink para Windows

Descarga los instaladores Docente y Alumno desde [la última versión](https://github.com/Brayanubigo/AulaLink-Actualizaciones/releases/latest).

Desde la versión 1.0.1, AulaLink busca actualizaciones sin cuenta ni clave de GitHub. Instala esta versión una vez para activar el canal; en un alumno ya vinculado, elige Actualizar AulaLink.

Este repositorio distribuye únicamente instaladores y metadatos de actualización. El código fuente de AulaLink permanece privado.

Las nuevas versiones se publican en Releases con ambos instaladores, latest.yml, aulalink-update.json y SHA256SUMS.txt.
